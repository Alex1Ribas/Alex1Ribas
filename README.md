## 🧠 Como eu trabalho

Meu processo normalmente segue esta ordem:

1. Entender o problema da empresa.
2. Compreender o fluxo operacional.
3. Definir as regras de negócio.
4. Modelar domínio e arquitetura.
5. Implementar.
6. Medir o impacto da solução.

Alguns princípios que procuro seguir:

- Arquitetura antes da implementação.
- Regras de negócio centralizadas no backend.
- Responsabilidade única para cada componente.
- Segurança considerada desde o início.
- Código preparado para manutenção.
- Evolução incremental (MVP antes da complexidade).
- Tecnologia como consequência da necessidade do negócio.

Também utilizo IA para acelerar tarefas repetitivas e pesquisas, mantendo as decisões arquiteturais e de negócio sob análise crítica.

## 🏗️ PG Terraplanagem

**Sistema de gestão para empresa de terraplanagem.**

### Problema

A empresa não possuía visibilidade sobre custos, faturamento e utilização das máquinas, dependendo de controles manuais.

### Solução

Desenvolvimento de um sistema completo contendo:

- Clientes
- Máquinas
- Operadores
- Serviços
- Manutenções
- Financeiro
- Controle de utilização das máquinas
- Troca de operadores durante execução
- Holerite por operador
- Exportação em PDF

Landing Page integrada ao WhatsApp e busca automática de endereço via ViaCEP.

### Resultado

Maior controle operacional e financeiro, redução de erros e base preparada para evolução futura.

**Stack**

React • Node • Express • MongoDB • JWT • OpenAPI
